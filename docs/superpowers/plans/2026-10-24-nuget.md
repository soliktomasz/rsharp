# NuGet PR 1: plan

Design: `docs/superpowers/specs/2026-10-24-nuget-design.md`.

## Core (`crates/rsharp-core/src/nuget/`)

1. `version.rs`: `compare(a, b)` in NuGet's order, `is_prerelease`. Unit tests on NuGet's ordering cases.
2. `sources.rs`: `Places { user, machine }` (the person's, or a test's), `SourceSet::load(root, &places)`:
   - the files in order (`ConfigFile` with place, feeds as written, disabled names, clear, problem);
   - the effective `Feed`s (name, source made absolute, enabled, defined in), nuget.org when there is no user file;
   - `allows(feed, id)` from `packageSourceMapping` (longest pattern; `*` matches all, `Prefix.*` a prefix).
   Parsed with `quick-xml`. Tests in `tests/nuget_sources.rs`.
3. `feed.rs`: `Package { id, version, description, authors, downloads, feeds }`; `Feed::for_source`: `V3` over
   `ureq` (service index cached, search, registrations with paged leaves, flat container) or `Folder` (nupkg nuspec
   through `async_zip`, flat and `id/version/` layouts). `FeedSet::search` and `FeedSet::versions` ask feeds on
   threads at once, merge, rank, count the unmapped. Feed failures are a list of `(feed, why)`. Tests use a loopback
   v3 server and a folder of generated nupkgs (`tests/nuget_feeds.rs`).
4. `change.rs`: `install(env, project, id, version, cancel, output)` and `remove(...)` through `templates::command::run`
   (made `pub(crate)`), refusing an empty word or one starting with `-`. Returns the dotnet result.

## App (`crates/rsharp-app/src/`)

5. `dock.rs`: `Tool::NuGet` (title "NuGet", icon `tw-nuget` from the IntelliJ platform's Apache-2.0 set, home
   BottomLeft). `actions.rs`: `ToggleNuGet` under Tools. `keymap.rs`: `cmd-7`/`alt-7`.
6. `nuget_view.rs`: the window entity, given the root folder and the projects (path, name, packages). Packages tab:
   search `TextField` (300 ms), feed chooser popup, Prerelease, list, details with version chooser and project rows,
   log, status. Sources tab: files and feeds. Emits `Wrote(paths)`. Loads sources in the background on first show and
   when told a nuget.config changed. Runs installs on the background executor; before and after, it saves open
   copies, records Local History and reloads buffers.
7. `window.rs` / `window/nuget.rs`: owns the view, feeds it projects after each evaluation, forwards nuget.config
   bursts, follows `Wrote` with `follow_written`.
